# 请你通过ADB连接我的安卓手机，自己探索学习各社交App的UI结构

## 你的任务
你现在是自动化测试工程师，通过USB调试连接我的手机，自己探索Soul、QQ、陌陌这些App的UI结构，摸清楚每个页面每个元素是什么，然后记录下来，最后整理成开发文档。

**不要等我告诉你哪个ID是什么，你自己抓UI树、自己分析、自己测试、自己总结规律。**

---

## 第一步：先确认连接
```
adb devices
```
确认设备 `1edce76b` 在线。

---

## 第二步：探索Soul App
### 2.1 打开Soul，探索消息列表页
1. 打开Soul：
```
adb shell monkey -p cn.soulapp.android -c android.intent.category.LAUNCHER 1
```

2. 等3秒，切到消息列表页（自己点底部tab找到聊天页面）

3. 抓UI树：
```
adb shell uiautomator dump /sdcard/ui.xml
adb pull /sdcard/ui.xml .
```

4. 自己分析这个UI树，找出：
   - 消息列表RecyclerView的ID是什么？
   - 每个会话项的根节点ID是什么？
   - 对方昵称的TextView ID是什么？
   - 最后一条消息预览的TextView ID是什么？
   - 时间的TextView ID是什么？
   - 未读数字的TextView ID是什么？
   - 头像的ImageView ID是什么？

5. 把这些ID记录下来，命名为"消息列表页元素清单"

---

   - 顶部标题（对方昵称）的ID是什么？
   - 返回按钮的ID是什么？

### 2.3 探索Soul语音转文字流程
1. 在聊天页里找一条语音消息

2. 自己测试长按：
```
adb shell input longpress <语音消息坐标> <时长2000毫秒>
```

3. 等1秒，截图看看弹出来什么菜单

4. **菜单可能是自绘浮层，UI树抓不到，你用截图+自己看，找到"转文字"三个字在屏幕上的哪个位置**

5. 点那个位置，等3秒，截图看看语音下面有没有转出文字

6. 抓UI树，找转出来的文字在哪个View里，ID是什么

7. 总结规律：
   - 长按语音后，菜单弹在什么位置？
   - "转文字"按钮相对于语音消息的坐标偏移是多少？
   - 转出来的文字在哪个View里？ID是什么？

- 语音消息长什么样？有什么特征？

每种消息类型都记录它的UI特征。
