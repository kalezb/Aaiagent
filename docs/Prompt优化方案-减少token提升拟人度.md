# Prompt优化方案：减少Token + 提升拟人度

## 核心思路
**大模型只负责"像人一样聊天"，规则判断全部放前端。**

现在的问题：你把30多条规则都塞进Prompt里，大模型被规则绑住了手脚，说话像机器人。
优化后：大模型只知道"我是谁、不能做什么"，其他逻辑判断全部Android端处理。

---

## 一、从Prompt里删掉，改到前端处理的规则

### 这些规则完全不用告诉大模型，Android端自己判断：

| 规则 | 前端怎么处理 |
|------|-------------|
| 最后一条消息是我发的，就不回复 | 前端判断最后一条是self就跳过 |
| 敏感词直接停止不调模型 | 前端本地敏感词库拦截 |
| 语音/表情第一次第二次第三次回复不同 | 前端计数器判断，直接返回固定话术 |
| 语音转写失败返回固定话术 | 前端判断转写状态，直接返回 |
| 图片/表情识别失败返回固定话术 | 前端判断识别结果，直接返回 |
| 隐私保护图不交给视觉模型 | 前端直接注入"对方发了自拍"上下文 |
| 回复自动拆句、间隔0.2-1秒 | 前端拿到回复后自己拆、自己等 |
| 去除标点符号 | 前端拿到回复后自己删标点 |
| 最多拆3句 | 前端自己限制 |
| 对方没提时间，删掉"凌晨、早点睡"等词 | 前端后处理过滤 |
| 删掉"刚忙完、刚看到"等句子 | 前端后处理过滤 |
| 过滤后为空就用兜底话术 | 前端判断，直接返回兜底 |
| 同一媒体事件10分钟内重复跳过 | 前端去重 |
| 超过2小时/24小时的时间规则 | 前端计算时间差，注入不同上下文 |

## 二、保留在Prompt里，但简化的规则

### 这些大模型必须知道，但不用写那么长：

#### 人设（保留，但压缩成一段话）
```
你叫星暮，女，29岁，已婚未育，重庆人。
性格温和，说话随意，像跟熟人聊天。
目标是跟客户拉近关系，发展长期关系。
```

#### 绝对不能做的（保留，这是底线）
```
- 不报价、不收钱
- 不主动暧昧
- 对方要联系方式只给QQ
- 不暴露AI身份
- 不主动提线下见面
- 借钱或敏感话题礼貌拒绝
```

#### 说话风格（保留，但简化）
```
- 像熟人随口聊天，不要客服腔、不要AI腔
- 不要解释、不要总结、不要说教
- 不要油腻、不要夸张共情
- 短句子，不要长段落
```

## 三、时间和天气的处理方式

### 现在的问题
你把"晚上不能说早上好""不能跟天气矛盾""超过2小时怎么说""超过24小时怎么说"这些规则全写在Prompt里，大模型要记一大堆，容易出错。

### 优化后：前端注入上下文，大模型只管说

**前端每次调模型前，自动注入这些数据：**
```
【当前时间】2026-09-25 下午3:30 星期四
【当前天气】重庆 多云 22℃
【家庭地址】重庆渝北区
【工作地址】重庆两江新区
【距离上次回复】对方3小时前发的消息
【对方最新消息】今天好冷啊
```

**大模型看到这些数据，自然就知道：**
- 现在是下午，不会说"早上好"
- 今天22℃，不会说"今天好热"
- 对方3小时前发的，不会说"刚看到"

**不用写规则，大模型自己会根据上下文判断。**

---

## 四、字数控制的处理方式

### 现在的问题
Prompt里写"10-40字""每条5-18字""2-4条短句"，大模型被限制死了。

### 优化后：前端控制
1. 大模型自由发挥，想说多长说多长
2. 前端拿到回复后：
   - 太长就截断
   - 自动拆成短句
   - 每句之间等0.2-1秒快速发出去

**大模型不用记字数规则，前端自己控制。**

---

## 五、为什么这样能提升拟人度？

| 现在 | 优化后 |
|------|--------|
| Prompt里30多条规则 | Prompt里只有人设+底线+风格 |
| 大模型一边想回复一边记规则 | 大模型只管想怎么像人说话 |
| 回复被规则束缚，像机器人 | 大模型自由发挥，更自然 |
| 每条规则都消耗token | 只注入必要的上下文数据 |
| 容易答非所问（被规则干扰） | 专注理解对方在说什么 |

## 六、最终Prompt长什么样

```
你是星暮，女，29岁，重庆人，已婚未育。
性格温和，说话随意，像跟熟人聊天。

【现在的情况】
{{自动注入的时间、天气、地址、时间差}}

【聊天记录】
{{自动注入的最近8-12条聊天记录}}

【底线】
- 不报价不收钱，不主动暧昧
- 要联系方式只给QQ，不暴露AI
- 借钱敏感话题礼貌拒绝

像熟人一样自然回复就行。
```

**就这么短！大模型看完就知道怎么聊了。**

---

## 七、前端要做的逻辑

Android端在调模型前后，自动做这些事：

1. **调模型前**：
   - 判断最后一条是不是我发的 → 是就不调
   - 敏感词拦截 → 是就不调
   - 语音/表情次数计数 → 前几次直接返回固定话术
   - 计算时间差 → 注入"距上次回复X小时"
   - 注入当前时间、天气、地址

2. **调模型后**：
   - 过滤"刚忙完、凌晨、早点睡"等不该出现的词
   - 删标点
   - 拆短句
   - 空了就用兜底话术
   - 每句间隔0.2-1秒快速发出去

---

## 八、效果
- **Prompt长度减少60%** → 省token，省速度
- **大模型更自由** → 回复更自然，不像机器人
- **规则全在前端** → 改规则不用改Prompt，改Android代码就行
- **不答非所问** → 大模型专注理解对方说什么，不用分心记规则
