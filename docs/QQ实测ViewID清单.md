## 四、语音转文字（实测跑通）

### 操作流程
1. 长按语音消息2秒
2. 弹出菜单（自绘浮层，UI树抓不到）
3. 菜单上面一排5个按钮：免提播放、转文字、2X、删除、多选
4. "转文字"是上面一排**第三个按钮**
5. 点完等2秒
6. 语音下面会出现转出来的文字

### 转出来的文字
| 元素 | View ID | 备注 |
|------|---------|------|
| 转文字结果 | `id/wql` | 在语音消息的root容器里 |

---

## 五、识别消息类型的判断逻辑

```
抓一条消息的UI树：
1. 有 mj0 → 文字消息
2. 没有 mj0，但有 wqe → 语音消息（看时长文字）
3. 有 mkr → 电话未接通
4. 有 f24 → 时间分隔条（不是消息，过滤掉）
5. 都没有 → 可能是图片/表情/其他，用截图+视觉模型处理
```

---

## 六、注意事项

1. QQ的ID很多是短的混淆码（mj0、f24、wqe、wql），不是有意义的名字
2. 语音转文字的菜单是自绘浮层，UI树抓不到，必须用截图找"转文字"三个字的位置
3. 转出来的文字wql在语音消息的容器里，不是单独的一条消息
4. f24是时间分隔条，不要当成对方发的消息
