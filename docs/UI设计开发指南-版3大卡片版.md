# UI设计开发指南 - 版3：大卡片现代版

## 一、整体风格
- 白底，圆角16dp卡片，阴影柔和
- 主色：绿色 #22c55e（托管中/开启状态）
- 强调色：红色 #ef4444（黑名单/错误）
- 文字：深灰 #1a1a1a 主标题，#999 副标题
- 所有按钮点击有缩放动画（scale 0.95）

## 四、前后端验证机制（所有设置改完都要验证）

**后端Base URL**：`https://ai-agent-api.pages.dev`
**所有请求都要带 `device_key` 参数**

| 设置项 | 按钮 | 后端接口 | 请求参数 | 成功提示 | 失败提示 |
|--------|------|----------|----------|----------|----------|
| 客服人设 | 验证按钮 | POST /api/config/save | device_key, persona_name | ✓ 人设已同步 | ✗ 同步失败 |
| 位置设置 | 保存位置按钮 | POST /api/config/save | device_key, home_city, home_area, work_city, work_area | ✓ 位置已保存 | ✗ 保存失败 |
| 设备钥匙 | 验证按钮 | POST /api/config/save | device_key | ✓ 钥匙有效 | ✗ 钥匙无效 |
| 平台切换 | 点平台按钮 | POST /api/config/save | device_key, platform | ✓ 已切换到Soul | ✗ 切换失败 |
| AI托管开关 | 开关 | POST /api/config/save | device_key, hosting_enabled | ✓ 托管已开启 | ✗ 开启失败 |
| 监控模式开关 | 开关 | POST /api/config/save | device_key, monitor_enabled | ✓ 监控已开启 | ✗ 开启失败 |
| 天气感知开关 | 开关 | POST /api/config/save | device_key, weather_enabled | ✓ 天气感知已开启 | ✗ 开启失败 |
| 时间感知开关 | 开关 | POST /api/config/save | device_key, time_enabled | ✓ 时间感知已开启 | ✗ 开启失败 |

**统一响应格式**：
```json
{
  "success": true,
  "message": "配置已保存",
  "data": { ... }
}
```

**错误响应**：
```json
{
  "success": false,
  "error": "设备钥匙无效"
}
```

## 五、开关样式规范
- 宽：44dp，高：24dp
- 开启：绿色 #22c55e 背景
- 关闭：灰色 #ccc 背景
- 滑块：白色圆形，20dp直径，有阴影
- 动画：0.2秒平滑过渡

---

## 六、按钮样式规范
- 圆角：10dp
- 内边距：上下12dp，左右16dp
- 字体：15sp 粗体
- 点击效果：缩放0.95 + 颜色变深

## 七、给AI开发的提示词
直接把下面这段话发给AI：

```
请按照这份UI设计指南开发Android App前端界面：
1. 整体用Jetpack Compose开发
2. 风格：大卡片现代版，白底圆角，主色绿色#22c55e
3. 页面结构：4个卡片（设备权限/平台与人设/AI托管控制/设置）
4. 所有按钮点击都要有前后端验证，显示成功/失败提示
5. 悬浮按钮可拖动，单击开关托管，长按打开主界面
6. 开关用绿色=开，灰色=关，有平滑动画
7. 不要做模型配置页面，模型配置在后端
```
