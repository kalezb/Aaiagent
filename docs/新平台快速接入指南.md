# 新社交平台快速接入指南

## 目标
给你一个新社交平台（比如微信、钉钉、探探等），你自己通过USB调试ADB去摸UI结构，然后写好适配器代码，让Agent能自动读消息、回消息、发消息。

---

## 第一步：找包名
```bash
# 先打开那个App，然后执行：
adb shell dumpsys window | findstr "mCurrentFocus"
```
输出里会显示当前App的包名，比如 `com.tencent.mm` 就是微信。

---

## 第二步：探索消息列表页

### 2.1 打开App，切到消息列表页
1. 用 `adb shell monkey -p 包名 -c android.intent.category.LAUNCHER 1` 打开App
2. 自己点底部tab切到消息列表
3. 截图确认：`adb shell screencap -p /sdcard/s.png && adb pull /sdcard/s.png .`

### 2.2 抓UI树
```bash
adb shell uiautomator dump /sdcard/ui.xml
adb pull /sdcard/ui.xml .
```

### 2.3 自己分析UI树，找这些元素：
| 元素 | 怎么找 |
|------|--------|
| 整个消息列表 | 找RecyclerView/ListView，isScrollable=true的那个 |
| 每个会话项 | 找会话项的根节点，一个会话就是一个item |
| 对方昵称 | 找会话项里的TextView，文字长度2-20个字 |
| 最后一条消息预览 | 找会话项里另一个TextView，文字比较长 |
| 时间 | 找会话项里的短文字（比如"10:30"、"昨天"） |
| 未读数字 | 找红色小圆点，里面有数字的那个 |
| 头像 | 找ImageView |

### 2.4 记录下来
把这些元素的View ID记下来，比如：
- 消息列表：`id/recycler_view`
- 会话项：`id/conversation_item`
- 昵称：`id/nickname`
- 未读数字：`id/unread_count`

---

## 第三步：探索聊天页

### 3.1 点进一个会话
1. 用 `adb shell input tap <x> <y>` 点一个会话进去
2. 等2秒，截图确认进了聊天页

### 3.2 抓UI树，找这些元素：
| 元素 | 怎么找 |
|------|--------|
| 输入框 | 找EditText，isEditable=true，在屏幕底部 |
| 发送按钮 | 找输入框右边的可点击按钮 |
| 每条消息项 | 找消息列表的item |
| 文字消息 | 找TextView，在消息气泡里 |
| 对方头像 | 找左边的ImageView |
| 我的头像 | 找右边的ImageView |
| 顶部标题 | 屏幕最上面中间，显示对方昵称 |
| 返回按钮 | 左上角的箭头 |

### 3.3 记录下来
把这些ID也记下来。

---

## 第四步：探索各种消息类型

在聊天页里，让对方发各种消息，然后抓UI树分析：

| 消息类型 | 怎么识别 |
|----------|----------|
| 文字消息 | 有TextView，在气泡里 |
| 语音消息 | 找语音气泡+时长文字（比如"0:27"） |
| 图片消息 | 找ImageView |
| 表情 | 找表情图/GIF |
| 时间分隔 | 屏幕中间的时间条 |
| 系统消息 | "你们已经是好友了"这种 |

每种类型都记录它的UI特征。

## 第五步：探索语音转文字

### 5.1 长按语音消息
```bash
adb shell input longpress <语音消息坐标> 2000
```

### 5.2 截图看弹出什么菜单
菜单可能是自绘浮层，UI树抓不到，用截图看：
- "转文字"三个字在屏幕上的哪个位置？
- 是在语音消息上方还是下方？
- 是第几个按钮？

### 5.3 点"转文字"按钮
```bash
adb shell input tap <转文字按钮坐标>
```

### 5.4 等3秒，截图看结果
语音下面有没有转出文字？转出来的文字在哪个View里？

### 5.5 总结规律
- 长按后菜单弹在什么位置？
- "转文字"按钮相对于语音消息的坐标偏移是多少？
- 转出来的文字在哪个View里？

## 通用规律（任何平台都适用）

1. **找不到ID就用截图+视觉模型** - 不要死磕UI树，有些App是自绘的
2. **点完等一下** - App加载慢，点完等2秒再检查
3. **进聊天页先验证标题** - 确认进对人了再读消息
4. **用户碰屏幕就暂停** - 不要跟用户抢控制权
5. **滑动后等稳定** - 滑完等列表不动了再读
6. **发送按钮多找几次** - 找不到就坐标兜底
