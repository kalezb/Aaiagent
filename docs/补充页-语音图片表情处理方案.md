## 一、语音消息：利用 App 自带的 "转文字" 功能

**不用自己做 ASR（语音转文字），直接点 App 自带的 "转文字" 按钮！**

### 流程



```
检测到语音消息
  ↓
找到语音消息旁边的"转文字"按钮
  ↓
点一下
  ↓
等 1-2 秒，文字转出来了
  ↓
读转出来的文字，当作对方发的内容
```

### 怎么找 "转文字" 按钮

**QQ：**



* 语音消息长按后会弹出菜单，里面有 "转文字" 选项

* 或者语音消息上直接有个 "转文字" 小按钮

**陌陌：**



* 语音消息上有个 "转文字" 按钮

* 找不到就长按语音消息，弹菜单里找

**Soul：**



* 语音消息旁边有个 "转文字" 按钮

### 实现代码思路



```
fun handleVoiceMessage(messageNode: AccessibilityNodeInfo) {
    // 1. 找语音消息上的"转文字"按钮
    val transcribeBtn = findTranscribeButton(messageNode)
    
    if (transcribeBtn != null) {
        // 2. 点转文字
        transcribeBtn.performAction(CLICK)
        // 3. 等文字出来
        delay(1500)
        // 4. 读转出来的文字
        val text = findTranscribedText(messageNode)
        // 5. 把文字当作对方发的消息
        addMessageToList("对方", text)
    } else {
        // 找不到转文字按钮 → 兜底
        addMessageToList("对方", "[语音消息]")
        sendReply("我听不了语音呀，你打字告诉我呗~")
    }
}
```

### 关键优势



* **不花钱**：用 App 自带的转文字，不需要接 ASR API

* **不增加延迟**：本地操作，1-2 秒搞定

* **准确度高**：App 自己的转文字肯定比第三方 ASR 准

## 二、图片消息：截图 + 视觉模型

### 流程



```
检测到图片消息
  ↓
截图当前聊天页
  ↓
把截图发给后端视觉模型
  ↓
视觉模型返回描述："这是一只橘猫趴在沙发上"
  ↓
把描述当作对方发的内容，调 LLM 生成回复
```

### 怎么实现

**后端加一个接口：**



```
POST /api/vision/describe
Body: { image: base64截图 }
返回: { description: "这是一只橘猫..." }
```

**Android 端：**



```
fun handleImageMessage(messageNode: AccessibilityNodeInfo) {
    // 1. 截图当前屏幕（Android 11+ 无障碍截图）
    val screenshot = captureScreenshot()
    // 2. 发给后端
    val desc = visionClient.describeImage(screenshot)
    // 3. 把描述当作消息内容
    addMessageToList("对方", "[图片] $desc")
}
```

### 成本



* 每张图一次视觉模型调用

* 比纯文字贵，但只在对方发图时才触发

* 日常聊天一天可能就几张图，成本很低

## 四、怎么判断消息类型（五类识别）



```
enum class MessageType {
    TEXT,      // 文字
    IMAGE,     // 图片
    STICKER,   // 表情包
    VOICE,     // 语音
    SYSTEM     // 系统消息
}

fun detectMessageType(node: AccessibilityNodeInfo): MessageType {
    // 1. 有文字气泡 → TEXT
    if (hasTextBubble(node)) return MessageType.TEXT
    
    // 2. 是系统通知 → SYSTEM
    if (isSystemMessage(node)) return MessageType.SYSTEM
    
    // 3. 有语音条 → VOICE
    if (hasVoiceBar(node)) return MessageType.VOICE
    
    // 4. 有图片框 → IMAGE
    if (hasImageView(node)) return MessageType.IMAGE
    
    // 5. 都不是 → STICKER（表情包）
    return MessageType.STICKER
}
```

## 六、优先级（先做什么后做什么）



1. **先做文字消息** — 已经在做了

2. **再做语音消息** — 点 "转文字" 按钮，不花钱，效果好

3. **最后做图片消息** — 截图给视觉模型，有成本但不多

**现在先做 1 和 2：**



* 文字正常处理

* 语音点 "转文字" 按钮读结果

* 图片 / 表情先回 "你打字告诉我呗"

等稳定了再接视觉模型看图。
